# alldot 产品功能文档

> alldot = allbot + ds-bot + ZCode 的合成体。本地优先的个人 AI Agent 系统。
> 代码仓库：`SxLiuYu/alldot`

## 产品定位

alldot 是一个跑在本机的个人 AI 助手。它能操作你的电脑（桌面、浏览器、文件、微信、飞书），自动完成任务，记住你的偏好，并且权限完全在你手里。核心理念：**你的电脑、你的数据、你的控制权。**

## 系统架构

```
用户（浏览器/微信/飞书/命令行）
        │
        ▼
  Bridge (8799)  ←── token 认证
        │
  ┌─────┴──────┐
  │  派发器     │  ←─ SQLite 账本（12 张表，单一写入口）
  │  调度器     │
  └─────┬──────┘
        │
  ┌─────┴──────────────────────────┐
  │  本机工人（local-worker）       │
  │  模型调用 → 工具派发 → 结果回收 │
  └─────┬──────────────────────────┘
        │
  ┌─────┴─────────────────────────────┐
  │  手（Hands）                      │
  │  files / desktop / browser /      │
  │  wechat / feishu / practice       │
  └───────────────────────────────────┘
```

### 六个常驻服务

| 服务 | 端口 | 用途 |
|---|---|---|
| Gateway | 18789 | allbot 主网关 |

| Windows-MCP | 8000 | Windows 桌面控制 |
| Playwright (logged) | 8931 | 已登录浏览器 |
| Playwright (clean) | 8932 | 干净浏览器 |

## 核心功能

### 1. 任务调度与执行

- **brain_task**：外部通过 MCP 创建任务，自动排队、派发、执行
- **自动拆里程碑**：任务没拆步骤时，用模型自动拆成 3-5 个里程碑
- **断点续跑**：每步存检查点，超时后从上次位置继续（最多 3 次）
- **超时控制**：默认 2 小时超时，可配置
- **防打转**：同一动作重复 2 次换做法，4 次强制收尾
- **硬失败处理**：权限不足等硬错直接停，不让模型硬试

### 2. 六只手（Hands）

| 手 | 能力 |
|---|---|
| **files** | 读/写/建/删文件和目录，根目录白名单 |
| **desktop** | 点击/输入/截图/窗口管理，原生 API 优先 |
| **logged_browser** | 已登录浏览器：填表/点击/导航/截图，带登录态 |
| **clean_browser** | 干净浏览器：无痕操作 |
| **wechat** | 读会话/发消息/截图，4 档请示卡 |
| **feishu** | 发消息/建日程/读文档/多维表格 |

### 3. 闸门（Gate）六档安全体系

| 档 | 含义 | 处理 |
|---|---|---|
| 1 | 读操作 | 直接放行 |
| 2 | 工作区内写 | 放行 + 快照 |
| 3 | 浏览器可逆 | 放行 |
| 4 | 有风险 | 请示卡问用户 |
| 5 | 交人手 | 暂停等人 |
| 6 | 禁止 | 直接拒绝 |

自动分类：命令执行、桌面键鼠、提交/支付/登录 → 高档。

### 4. Sentinel 权限系统

按服务粒度控制读/写/exec 三级权限：

```json
{
  "files": { "read": true, "write": true, "exec": false },
  "desktop": { "read": true, "write": true, "exec": false },
  "wechat": { "read": true, "write": true, "exec": false },
  "exec": { "read": false, "write": false, "exec": true }
}
```

- 13 个默认服务策略
- 运行时可调（改 `~/.allbot/dot/sentinel.json`）
- 工具派发前强制执行，先于闸门

### 5. 跨会话记忆

- **记忆存储**：`~/.allbot/dot/memory.jsonl`，每条带类型/范围/置信度
- **三类记忆**：用户偏好（user）、任务经验（task）、环境上下文（context）
- **自动注入**：工人开工前，把用户偏好和相关经验拼进系统提示词
- **自动提炼**：任务完成后，用规则从消息中提取偏好（「以后/总是/不要」→ user 记忆，任务成败 → task 经验）
- **检索**：按 scope 匹配 + 关键词匹配 + 置信度加权排序

### 6. 主动监控（Proactive）

- **三种触发器**：文件变化 / 定时 / 网页变化（接口留好）
- **冷却期**：每触发器可设冷却秒数，防重复
- **轮询模式**：每 30 秒检查一次（不用 fs.watch，Windows 上不可靠）
- **持久化**：触发器存 `~/.allbot/dot/triggers.json`
- 触发后自动创建任务走正常执行流程

### 7. Agent 个性化

- **名字 + 头像**：默认 Dot 🤖，可改
- **说话风格**：友好 / 专业 / 简洁 / 幽默 / 技术 五选一
- **语气强度**：1（温和）到 5（直接）
- **语言偏好**：中文 / 英文 / 自动
- **自定义指令**：自由文本，注入每次会话
- 配置存 `~/.allbot/dot/profile.json`

### 8. Web 聊天界面

- 暗色主题，现代 UI
- 侧边栏任务列表 + 消息气泡
- 进度指示器、审批卡片
- 自适应输入框
- 路由：`GET /chat`

### 9. DesignAnything 长程任务集成

- **Task Contract**：`parseContract` / `checkContract` / `nextDeliverable`
- **意图-执行图**：步骤 + 产物 + 里程碑绑定
- **确定性控制器**：按合同推进，不跑偏
- **双循环**：工人循环 + 自动规划循环
- **五种约束检查** + 三种交付物追踪

### 10. 自我优化

- 每天 2 条提案，10 分钟执行窗口
- 三路证据：用户反馈事件、好评/差评按钮、执行统计
- `deploy.ts` 自动流程：备份 → 打补丁 → 全量测试 → 回滚或归档
- 改动经审批后生效

### 11. 账本（Ledger）

- SQLite 12 张表，单一写入口
- 任务、步骤、审批、锁、事件、快照全记录
- 哈希链防篡改
- 断电恢复（recover）
- 账本清扫脚本

### 12. 部署与分发

- **安装包**：C# WinForms 安装器（.NET 4.0 兼容）
- **便携版**：`build-dist.ps1` 一键打包
- **Windows exe**：C# WebView2 嵌入式 UI（877 KB 单文件）
- **看门狗**：dot-keeper 每 5 分钟巡检，异常自动重启
- **开机自启**：schtasks 注册
