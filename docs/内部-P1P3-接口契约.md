# P1–P3 接口契约（2026-11-27，后端与网页照此对接）

> 只锁**返回形状**与**路径**，内部实现由后端自己定。鉴权与现有 `/api/*` 一致（桥 token：header `x-dot-bridge-token`、Bearer 或 `?token=`）。

## 1) GET /api/doctor

体检结果的人话版本。数据源是 `~/.allbot/dot/state/keep.json`，再加运行期知道的配置错误。

```json
{
  "ok": true,
  "overall": "green" | "yellow" | "red",
  "updatedAt": "2026-11-27T05:00:00.000Z",
  "blocked": false,
  "items": [
    {
      "id": "bridge",
      "title": "8799 桥",
      "state": "green" | "yellow" | "red",
      "blocks": false,
      "detail": "GET /health 通",
      "fix": "restart_tunnel",
      "fixLabel": "重连隧道"
    }
  ],
  "configError": { "path": "keepalive.tunnelPort", "message": "应该是数字，你写的是字符串" }
}
```

- `blocks`：这一项挡不挡派单。`blocked` = 任意 `blocks:true` 且 `state` 不是 green。
- `fix` 与 `fixLabel`：能一键修就给动作 id 与按钮字；不能修给 `null`。
- `configError`：最近一次配置校验失败；没有就是 `null`。

## 2) POST /api/fix

```json
请求 { "action": "start_gateway" }
成功 { "ok": true, "detail": "已起网关（PID 71428）" }
失败 { "ok": false, "error": "unknown_action" | "fix_failed", "message": "……" }
```

动作 id 至少包含：`start_gateway`、`restart_tunnel`、`start_playwright`、`start_clean_browser`、`start_windows_mcp`、`prune_artifacts`、`clear_report_queue`。

## 3) GET /api/diagnostics

一键诊断，返回**已脱敏**的纯文本（不得含 token、IP、端口、邮箱、绝对用户目录）。

```json
{ "ok": true, "text": "alldot 诊断\n…" }
```

## 4) GET /api/approvals

```json
{
  "ok": true,
  "items": [
    {
      "id": "apv_...",
      "taskId": "task_...",
      "tier": 4,
      "summary": "在 D:/work 里删 3 个文件",
      "createdAt": "2026-11-27T05:00:00.000Z",
      "expiresAt": "2026-11-27T05:30:00.000Z",
      "expired": false
    }
  ]
}
```

审批有效期默认 30 分钟（`approvals` 表若没有过期列，按 created_at 推算，不改表结构）。

## 5) POST /api/approvals/answer

```json
请求 { "id": "apv_...", "answer": "agree" | "reject" }
成功 { "ok": true, "decision": "agree" | "reject" | "expired" }
失败 { "ok": false, "error": "not_found" | "expired" | "already_decided", "message": "……" }
```

过期后按「拒绝」写进账本，理由写「超时」。旧卡片重复点要返回 `already_decided` 或 `expired`，不能重复记账。

## 6) 已有、网页要开始用

- `POST /feedback`：**实际实现认的是 `{ "task_id": "task_...", "verdict": "good" | "bad" | "对" | "不对", "note": "…" }`**（见 `routes.ts:handleFeedback`），不是 `{taskId, vote}`。网页按 `task_id` / `verdict` 发。
