# Meta Muse 产品功能分析

> 基于 2026-09-08 发布的公开资料整理。Muse 是 Meta 推出的个人 AI Agent 产品。

## 产品定位

Muse 是一个跑在云端的个人 AI 助手。它不像 ChatGPT 那样等你问才答，而是主动感知环境、提前执行任务、通过 WhatsApp 推送结果。核心理念：**AI 替你做事，不是帮你做事。**

## 核心功能

### 1. 主动任务执行（Proactive Behavior）

- 持续监控指定事件（文件变化、日历、网页更新、邮件到达等）
- 触发条件满足后自动派任务执行，不需要用户每次发指令
- 结果推送到用户常用的聊天渠道
- 有冷却期机制防止重复触发

### 2. Sentinel 权限系统

- 按服务粒度控制 AI 能做什么：每个服务分 **读 / 写 / 无** 三级权限
- 用户可以在设置里逐服务调整
- 高危操作（支付、删除、提交表单）需要人工确认
- 优先级高于工具执行，先检查再动手

### 3. 跨会话记忆（Persistent Memory）

- 记住用户的偏好、习惯、历史交互
- 自动从对话和任务结果中提取关键信息
- 下次会话自动注入相关记忆
- 记忆分层：用户偏好 > 任务经验 > 环境上下文

### 4. 长程任务管理

- 支持数小时甚至数天的长任务
- 自动检查点保存，超时后断点续跑
- 最大恢复次数限制，防止无限重试
- 任务拆成里程碑，逐步推进

### 5. Agent 个性化

- 用户可以给 Agent 起名字、选头像
- 选择说话风格（友好/专业/简洁/幽默/技术）
- 自定义额外指令和语气强度
- 影响所有会话的回复方式

### 6. 多渠道接入

- WhatsApp 为主要交互渠道
- 支持语音消息
- 推送通知带操作按钮（批准/拒绝/查看详情）

### 7. 浏览器与桌面操作

- 能操作网页（填表、点击、导航、截图）
- 能操作桌面应用
- 带视觉理解（截图后判断界面状态）
- 危险操作前先截图留证

### 8. 商业合作伙伴集成

- Stripe：支付处理
- Shopify：电商操作
- 其他合作伙伴的 API 集成

## 技术架构

| 层 | 说明 |
|---|---|
| 运行环境 | 云端 VM（每个用户一个） |
| 模型 | Muse Spark（Meta 自研，专门为 Agent 优化） |
| 权限 | Sentinel 系统，服务级读写控制 |
| 交互 | WhatsApp / 语音 / Web |
| 记忆 | 持久化存储，跨会话可用 |
| 计费 | 免费层 + $20/月 + $100/月 三档 |

## 定价

| 档位 | 价格 | 能力 |
|---|---|---|
| 免费 | $0 | 基础任务，有限次数 |
| Plus | $20/月 | 更多任务、更长程、更多集成 |
| Pro | $100/月 | 无限任务、优先算力、高级集成 |

## 优势

- 云原生：24/7 在线，不依赖用户设备
- 主动性强：不是被动问答
- 记忆完整：真正记得用户
- 权限清晰：Sentinel 给用户安全感
- 开箱即用：WhatsApp 零门槛接入

## 局限

- 依赖云端：隐私顾虑
- 依赖 Meta 生态：WhatsApp 绑定
- 不能操作本地程序：只能做云端能做的事
- 闭源：不能自定义底层行为
