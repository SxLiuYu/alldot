## 四、要你配合的三小段（合计约半小时）

三段的共同前提：施工的人先把服务起好、把脚本参数核对一遍，再叫你；你到座位后只做「打开某个窗口、点几下」这类事，不用装东西、不用改配置。

### 第 1 段：借微信读一次界面（约 10 分钟，S0-5）

- **你做什么**：打开微信主窗口，保持登录，停在聊天列表那一页；脚本跑的一两分钟里别动鼠标键盘；跑完听施工的人说一句「读到了」就可以继续用。
- **施工的人做什么**：先把 Windows-MCP 起到 8000（`schtasks /run /tn "\windows-mcp-server"`，或按它自己的启动方式；起来后 `curl` 一次 MCP initialize 确认通）；再跑
  `node build/tools/smoke/S0-5.mjs --app "C:/Program Files/Tencent/Weixin/Weixin.exe" --probe`。
- **什么算过**：输出里具名控件数 `> 0`，verdict 不是 `human_only`。
- **已知缺口**：脚本 `--probe` 只做只读快照，**不做方案里「点中一个无害按钮」**那半条（grep `build/tools/smoke/S0-5.mjs`，参数只有 `--probe / --clicks / --save / --threshold / --mcp-url`）。要满足原文标准，得手工点一次，或给脚本加一个 `--click-first`。这一条我不会假装跑过。

### 第 2 段：借 Chrome 读一次用户名（约 10 分钟，S0-6）

- **施工的人先做**（可以提前做完，不用你在场）：`npm install -g @playwright/mcp`，装不上就换源 `npm install -g @playwright/mcp --registry=https://registry.npmmirror.com`；起服务 `npx @playwright/mcp --extension --port 8931`（端口和 `--extension` 口径见方案 :823），然后 `curl` 一下 8931 确认在听。
- **你做什么**：Chrome 里会弹一次装扩展的提示，点「允许」（商店打不开就让施工的人用开发者模式加载解压目录，你只需在「加载已解压的扩展程序」确认一次）；然后打开一个你已经登录的网站（自己的后台、常用的那个就行），停在这个页面别切标签、别关窗。
- **施工的人做什么**：用 MCP 客户端读一次页面结构/标题/账号名，记录有没有新窗口弹出、有没有抢焦点。
- **什么算过**：读出你的用户名；没有新窗口；你没感觉到鼠标被抢。
- **不过怎么办**：退到「干净浏览器＋你在里面登录一次」，方案已经写好这条退路（S0-6 那行「不过怎么办」）。

### 第 3 段：在提问卡上答一次题（约 10 分钟，S0-8）

- **施工的人先做**：把 ds-bot 起起来（现在 8797 和 8799 都是 closed），在练习文件夹外派一件需要批准的小事（比如往桌面写一个文本文件），让请示卡弹出来。
- **你做什么**：第一次点「同意」；第二次点「不同意」；第三次故意不点，晾 2 分钟再决定。
- **什么算过**：同意 → 它干完；不同意 → 它收手，不留半截文件；晾 2 分钟 → 任务转成「等待输入」、状态页看得到，之后点同意能从原处接着走、不重做。
